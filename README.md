## Summary

This assignment implements four Reinforcement Learning problems using Python and Gymnasium.
Problem 1 designs a pick-and-place robot MDP. Problem 2 performs manual Value Iteration on
a 2x2 gridworld. Problem 3 implements Standard and In-Place Value Iteration on a 5x5
gridworld using object-oriented agents. Problem 4 implements Off-Policy Monte Carlo with
Weighted Importance Sampling on the same environment.

## Assumptions and Known Limitations

- **Action space correction:** Assignment lists a3=down (duplicate of a2). Corrected to
  a3=left per Sutton & Barto (2018) Example 4.1 standard 4-directional gridworld convention.
- **gamma for Problem 2:** gamma=1.0 used (not specified in problem) — standard for
  finite-horizon manual VI demonstrations.
- **MC truncation bias:** With uniform random policy, some episodes hit MAX_STEPS=500
  without reaching the goal. Episode length stats are reported in the notebook.
